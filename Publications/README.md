# Selection-index publication review

This folder contains an integrated analytical review and seven individual Markdown chapters.

## Main deliverables

- `00_integrated_review.md`: one detailed report covering all uploaded documents.
- `selection_index_publications_review.html`: browser-ready HTML version of the integrated report.
- `01_...md` to `07_...md`: individual detailed reviews.

## Nature of the output

The files are analytical rewrites and structured technical summaries. They preserve the principal methods, equations, sample sizes, numerical results, interpretation, strengths, and limitations without reproducing the publications verbatim.
