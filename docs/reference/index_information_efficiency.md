# Cunningham information-deletion efficiency

A value of 0.98 means that the index after deleting one information
variable retains 98 percent of the full optimum-index standard
deviation.

## Usage

``` r
index_information_efficiency(index)
```

## Arguments

- index:

  A Smith-Hazel index or a general economic index.

## Value

A data.table with one row per information variable.

## References

Cunningham EP (1969). The relative efficiencies of selection indexes.
*Acta Agriculturae Scandinavica* 19:45-48.
